# Переписування тексту в іншому стилі

Лабораторна робота 8 з курсу «Основи великих мовних моделей» (НУ «Львівська політехніка»).

Вебзастосунок переписує текст в обраному стилі: офіційно-діловому, розмовному, простими словами,
науковому або художньому. На кожен запит робить один виклик мовної моделі `openai/gpt-oss-20b`
через Groq API і показує лише переписаний текст, без вступів на кшталт «Ось ваш текст».

## Як це влаштовано

- `rewriter.py`: промпт і виклик моделі. Правила для моделі в системному повідомленні,
  текст користувача в тегах `<text>`, тому команди всередині тексту модель не виконує, а переписує.
  Міркування gpt-oss вимкнено (`include_reasoning=False`), відповідь додатково підчищається.
- `streamlit_app.py`: інтерфейс на Streamlit. API-ключ Groq вводиться на сторінці і ніде не зберігається.

## Локальний запуск

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Потрібен API-ключ Groq: безкоштовно на [console.groq.com](https://console.groq.com/keys).
